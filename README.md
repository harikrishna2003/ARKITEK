# 🏢 ARKITEK
A full-featured **Office Management System** built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) with a sleek and responsive UI powered by **Syncfusion UI** and **Tailwind CSS**.

## 🚀 Tech Stack

- **Frontend**: React.js, Tailwind CSS, Syncfusion UI
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **Authentication**: JWT (JSON Web Tokens)
- **Deployment-ready**: Designed for scalability and modular extension

---

## ✨ Features

- 🔐 **Authentication & Authorization**
  - JWT-based login system
  - Role-based access control (Admin, Manager, Employee)

- 👥 **Employee Management**
  - View and manage employee attendance
  - Submit and track leave requests
  - Role-based dashboard views

- 📋 **Project & Task Management**
  - Create, assign, and manage tasks
  - Integrated calendar for scheduling and tracking
  - Notes section for each project/task

- 🔁 **Real-Time Updates**
  - Instant reflection of changes across users
  - Live updates for task status, attendance, and leaves

- 🎨 **Modern UI**
  - Built with Syncfusion components for rich user experience
  - Responsive and clean layout using Tailwind CSS

## 🛠️ Setup Instructions

### Prerequisites

- Node.js and npm installed
- MongoDB Atlas account and cluster setup

### 1. Clone the Repository

```bash
git clone https://github.com/harikrishna2003/ARKITEK.git
cd ARKITEK

# Backend setup
cd server
npm install
# Create a .env file with MongoDB URI and JWT secret
nodemon index.js

#Frontend setup
cd client
npm install
npm run dev
```
